# カワウソ・スパ・タイクーン プライバシーポリシー

[한국어](../privacy) · [English](../en/privacy) · [中文](../zh/privacy) · [Español](../es/privacy)

キム・ミニョン（以下「開発者」）は、モバイルゲーム「カワウソ・スパ・タイクーン」（以下「本ゲーム」）を提供するにあたり、利用者の個人情報を大切に扱います。本ポリシーでは、本ゲームがどのような情報をなぜ処理するのか、利用者にどのような権利があるのかを説明します。

## 1. アカウントとクラウドセーブ

本ゲームには会員登録がなく、氏名・電話番号などの入力は求めません。

- **クラウドバックアップ**：機種変更後も続きから遊べるよう、ゲームの進行データ（施設、通貨、スタッフ、ミッション、チュートリアルの段階など）をGoogle Firebaseのサーバーにバックアップします。ログインしない場合は、ランダムに作成した匿名アカウントIDでバックアップします。
- **Google・Appleでのログイン（任意）**：設定からログインすると、そのアカウントの固有IDとメールアドレス（Appleの「メールを非公開」を使う場合は中継アドレス）を受け取り、バックアップをそのアカウントに紐付けます。パスワードは受け取りません。
- バックアップやログインを使わなくても、ゲームはそのまま遊べます。

## 2. 自動的に処理される情報

| 項目 | 目的 | 処理者 |
| --- | --- | --- |
| 広告識別子（IDFA・広告ID）、端末情報（機種、OSバージョン、言語）、IPアドレス、広告とのやり取り | 広告の表示と成果測定、不正クリックの防止 | Google AdMob |
| アプリ利用記録（チュートリアル進行、施設の建設・アップグレード、店舗の開放、広告報酬の受け取りなどのゲームイベント）、アプリインスタンスID、端末情報 | ゲーム改善とバランス調整のための統計 | Google Firebase Analytics |
| アプリインスタンスID、端末情報 | ゲーム設定値（バランス倍率、イベント日程など）の配信 | Google Firebase Remote Config |
| 異常終了の記録（エラー内容、端末・OS情報） | 不具合の修正と安定性の向上 | Google Firebase Crashlytics |
| IPアドレス（時刻確認のリクエスト） | 端末の時計を変更して放置報酬が不正に増えないよう、Googleのサーバー時刻を確認 | Google |
| 購入履歴（商品、取引番号） | 有料商品の付与と購入の復元 | Apple App Store、Google Play |
| アカウントID（匿名またはGoogle・Apple）、メールアドレス（ログイン時）、ゲーム進行データ、端末識別用のランダムID | クラウドバックアップと別の端末での読み込み | Google Firebase（Authentication、Cloud Functions、Firestore） |
| 購入確認情報（商品、取引番号、購入トークン） | 購入が実際に行われたかをストアに確認し、不正な付与を防止 | Google Firebase Cloud Functions、Apple App Store、Google Play |

- 支払い手段の情報（カード番号など）は各ストアが処理し、開発者は受け取りません。
- iOSでは、まずApp Tracking Transparency（ATT）の許可を確認し、許可されない場合は広告識別子を使用しません。
- 欧州経済領域・英国・スイスなどでは、Googleの同意管理プラットフォーム（UMP）で広告に関する同意を取得します。ゲーム内の**設定 → 広告のプライバシー設定**からいつでも変更できます。

## 3. 保存期間

- 端末に保存されたゲームデータ：アプリを削除すると一緒に削除されます。
- クラウドバックアップとアカウント情報：アカウントを削除するまで保存し、削除するとすぐに消去します。最終利用から2年が経過した匿名アカウントのバックアップも消去します。
- 購入確認記録（取引番号）：同じ購入が二重に付与されないよう、アカウント削除後も最長5年保存します。
- Firebase Analyticsのデータ：取得日から最長14か月保存した後、削除されます。
- Crashlyticsのデータ：取得日から最長90日保存した後、削除されます。
- 広告・購入に関する情報：各提供者（Google、Apple）のポリシーに従います。

## 4. 第三者提供と処理の委託

開発者は利用者の情報を販売しません。上記2.のサービス提供者にのみ、その目的の範囲内で処理を委託します。各提供者は海外（米国など）にサーバーを置く場合があります。

- Googleプライバシーポリシー: https://policies.google.com/privacy
- Googleによるパートナーアプリの情報の使用: https://policies.google.com/technologies/partner-sites
- Appleプライバシーポリシー: https://www.apple.com/jp/legal/privacy/

## 5. 利用者の権利

- 広告トラッキングの拒否：iOS **設定 → プライバシーとセキュリティ → トラッキング**、Android **設定 → プライバシー → 広告**で変更できます。
- 広告に関する同意の変更：ゲーム内の**設定 → 広告のプライバシー設定**（対象地域のみ表示）で変更できます。
- ゲームデータの削除：アプリを削除すると端末内のゲームデータはすべて削除されます。
- アカウントとクラウドバックアップの削除：ゲーム内の**設定 → クラウドセーブ → アカウントを削除**ですぐに削除できます。アプリを使えない場合は[アカウント削除のご案内](delete-account)をご覧のうえ、メールでご依頼ください。
- その他の開示・訂正・削除のご依頼は、下記の連絡先までお送りください。

## 6. 子どもの個人情報

本ゲームは14歳未満の子どもを対象としておらず、子どもの個人情報を故意に取得することはありません。

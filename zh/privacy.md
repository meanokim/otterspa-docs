# 水獭汗蒸房大亨 隐私政策

[한국어](../privacy) · [English](../en/privacy) · [日本語](../ja/privacy) · [Español](../es/privacy)

金敏英（以下简称“开发者”）在提供手机游戏《水獭汗蒸房大亨》（以下简称“本游戏”）时，重视用户的个人信息。本政策说明本游戏处理哪些信息、为何处理，以及用户享有哪些权利。

## 1. 账号与云存档

本游戏无需单独注册，不会要求输入姓名、电话号码等信息。

- **云备份**：为了换设备后也能继续游戏，游戏进度数据（设施、货币、员工、任务、教程阶段等）会备份到 Google Firebase 服务器。未登录时，使用随机生成的匿名账号 ID 进行备份。
- **使用 Google 或 Apple 登录（可选）**：在设置中登录后，我们会获取该账号的唯一 ID 和电子邮箱（使用 Apple“隐藏邮件地址”时为中转地址），并将备份关联到该账号。我们不会获取密码。
- 不使用备份或登录也可以正常游玩。

## 2. 自动处理的信息

| 项目 | 目的 | 处理方 |
| --- | --- | --- |
| 广告标识符（IDFA、广告 ID）、设备信息（型号、系统版本、语言）、IP 地址、广告互动 | 展示广告、衡量广告效果、防止无效点击 | Google AdMob |
| 应用使用记录（新手教程进度、设施建造与升级、开设分店、领取广告奖励等游戏事件）、应用实例 ID、设备信息 | 用于改进游戏和调整平衡的统计 | Google Firebase Analytics |
| 应用实例 ID、设备信息 | 下发游戏设置（平衡倍率、活动日程等） | Google Firebase Remote Config |
| 异常退出记录（错误内容、设备与系统信息） | 修复错误、提升稳定性 | Google Firebase Crashlytics |
| IP 地址（时间校验请求） | 校验 Google 服务器的当前时间，防止通过修改设备时钟不正当地增加离线收益 | Google |
| 购买记录（商品、交易编号） | 发放付费商品及恢复购买 | Apple App Store、Google Play |
| 账号 ID（匿名或 Google、Apple）、电子邮箱（已登录时）、游戏进度数据、用于区分设备的随机 ID | 云备份及在其他设备上读取 | Google Firebase（Authentication、Cloud Functions、Firestore） |
| 购买验证信息（商品、交易编号、购买令牌） | 向商店确认购买真实有效，防止异常发放 | Google Firebase Cloud Functions、Apple App Store、Google Play |

- 支付信息（如银行卡号）由各应用商店处理，开发者不会获取。
- 在 iOS 上，游戏会先请求“应用跟踪透明度”（ATT）授权；若用户拒绝，则不使用广告标识符。
- 在欧洲经济区、英国、瑞士等地区，通过 Google 的同意管理平台（UMP）征得广告隐私同意。可随时在游戏的**设置 → 广告隐私设置**中更改。

## 3. 保存期限

- 设备中的游戏数据：卸载应用时一并删除。
- 云备份与账号信息：保存至删除账号为止，删除后立即清除。超过 2 年未使用的匿名账号备份也会被清除。
- 购买验证记录（交易编号）：为防止同一笔购买被重复发放，删除账号后仍最多保存 5 年。
- Firebase Analytics 数据：自收集之日起最多保存 14 个月后删除。
- Crashlytics 数据：自收集之日起最多保存 90 天后删除。
- 广告与购买信息：遵循各提供方（Google、Apple）的政策。

## 4. 向第三方提供与委托处理

开发者不会出售用户信息。仅在上述第 2 条所列目的范围内委托相应服务提供方处理，各提供方可能在境外（如美国）设有服务器。

- Google 隐私权政策：https://policies.google.com/privacy
- Google 如何使用合作伙伴应用的信息：https://policies.google.com/technologies/partner-sites
- Apple 隐私政策：https://www.apple.com/legal/privacy/

## 5. 用户的权利

- 拒绝广告跟踪：iOS **设置 → 隐私与安全性 → 跟踪**；Android **设置 → 隐私 → 广告**。
- 更改广告隐私同意：在游戏的**设置 → 广告隐私设置**中更改（仅在适用地区显示）。
- 删除游戏数据：卸载应用即可删除设备中的全部游戏数据。
- 删除账号与云备份：在游戏的**设置 → 云存档 → 删除账号**中即可立即删除。如无法使用应用，请参阅[账号删除说明](delete-account)通过邮件申请。
- 其他查阅、更正、删除请求，请通过下方联系方式与我们联系。

## 6. 儿童个人信息

本游戏不以 14 岁以下儿童为对象，也不会在知情的情况下收集儿童的个人信息。
